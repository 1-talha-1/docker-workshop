# Docker & Containerization Workshop

A comprehensive 3-day technical training program on Docker and containerization technologies with hands-on implementation of a document analysis system.

## Overview

This repository contains all materials for the Docker & Containerization Workshop, including:
- Lab guides and exercises
- Technical documentation


## Workshop Structure

The workshop is organized into 12 modules across 3 days:

- **Day 1:** Containerization Foundations & Docker Essentials
- **Day 2:** Container Customization & Document Analysis System Implementation
- **Day 3:** Multi-Container Orchestration & Production Deployment

## Getting Started

### Prerequisites

- Laptop/workstation with minimum 8GB RAM and 4+ CPU cores
- 50GB free disk space
- Docker Engine or Docker Desktop installed
- Git client and code editor (VS Code recommended)
- Basic command line familiarity
- Unrestricted internet access for Docker Hub and GitHub

### Installation

1. Clone this repository:
   ```
   git clone https://github.com/1-talha-1/docker-workshop.git
   ```

2. Verify Docker installation:
   ```
   docker --version
   ```
